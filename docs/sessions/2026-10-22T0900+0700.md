## Temuan & perbaikan selama sesi

- **Operasi panjang menahan mutex dokumen** → render (dan pohon aksesibilitas WebView2) terblokir
  sehingga UI tampak beku. `save_as` kini memakai snapshot: lock hanya saat snapshot, penulisan &
  verifikasi di luar lock. `extract`/`merge` sudah tidak memegang lock.
- **`stroke_color()` pdfium-render** → access violation pada anotasi ber-`/AP`; tidak dipanggil
  aplikasi. Regression: canary `stroke_color_crash_canary` (gagal = cacat masih ada).
- **Dialog "Confirm Save As" (TaskDialog)** → tombolnya hanya merespons input keyboard sungguhan;
  harness E2E tidak boleh mengetik ke layar pengguna → UI-04 NOT_RUN.
- **Pohon aksesibilitas WebView2** kadang terlambat; harness memverifikasi lewat berkas (PyMuPDF)
  dan teks UI, bukan hanya teks UI.
