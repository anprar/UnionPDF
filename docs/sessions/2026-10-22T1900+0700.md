## Bug nyata yang ditemukan & diperbaiki

1. **Rentang halaman diabaikan saat konversi** (semua halaman dikonversi) → kini diparse & dihormati (uji Rust).
2. **Auto-scroll menghitung scrollnya sendiri sebagai interaksi pengguna** → jeda permanen; kini ada jendela aba-aba 250 ms.
3. **Tombol kehilangan nama aksesibel** saat label disembunyikan di layout sempit → `aria-label` ditambahkan.
4. **Bookmark PDF tidak tampil** di panel → nama aksesibel tombol outline berisi "Bab 1 1" (judul+nomor); kini `aria-label` = judul.
5. **Path default gabung relatif** → kini di folder dokumen sumber.
