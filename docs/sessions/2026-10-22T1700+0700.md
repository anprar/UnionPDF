## Error / batasan

- `webviewInstallMode` harus berada di `bundle.windows` (bukan `bundle`) — kesalahan konfigurasi
  yang tertangkap saat build bundel.
- Prompt "Confirm Save As" Windows hanya merespons keyboard sungguhan → U-04 NOT_RUN.
- Seret mouse (anotasi) tidak dapat diuji otomatis → M-01…M-24.
- Belum ada pencarian/find (butuh indeks teks seluruh dokumen) — teks per halaman sudah tersedia
  sehingga bisa ditambahkan tanpa mengubah backend.
- Redaksi tetap ditunda; fixture `rs07_redact.pdf` + temuan "nilai field lama masih ada di
  appearance stream" dipertahankan.
